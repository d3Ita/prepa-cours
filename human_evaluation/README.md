# Évaluation humaine

**Cette étude n'a pas été réalisée, et ce dossier ne contient aucun résultat.** Il prépare la comparaison des sorties avec le jugement d'enseignants, seul moyen d'approcher directement la qualité pédagogique.

## Déroulement prévu

1. Préparer les sorties du benchmark : retirer le nom du mode, puis attribuer un identifiant anonyme à chaque jeu de documents.
2. Présenter les jeux dans un ordre aléatoire, avec le cours d'origine, à au moins deux évaluateurs de la matière.
3. Faire remplir la [grille](rubric.md) sans contact entre évaluateurs.
4. Enregistrer les notes dans [`resultats_modele.csv`](resultats_modele.csv), une ligne par note.
5. Mesurer l'accord entre évaluateurs avant de comparer les modes, puis croiser ces notes avec les métriques du benchmark. Cela indiquera aussi si les indicateurs automatiques suivent ou non le jugement humain.

Avant toute étude, vérifiez les règles qui s'appliquent à votre établissement, recueillez le consentement des évaluateurs et n'utilisez aucune donnée d'élève.
