# Séance 3 : plusieurs agents, risques et protections
Licence 3 informatique, 2 h. Matériel : vidéoprojecteur, feuilles, QCM imprimés.

## 0-10 min — Rappel
- Objectif visé : O6
- Le prof : fait rappeler le rôle des outils et de la mémoire.
- Les élèves : répondent à l'oral.
- Support : diapo 1

## 10-25 min — Un agent ou plusieurs ?
- Objectif visé : O6
- Le prof : présente le rôle du superviseur, les avantages et les inconvénients.
- Les élèves : posent leurs questions.
- Support : diapos 2 et 3

## 25-45 min — Activité : choisir une architecture
- Objectif visé : O6
- Le prof : propose des cas d'usage. [À VÉRIFIER] Les cas ne viennent pas du cours.
- Les élèves : choisissent par deux un agent ou plusieurs agents et justifient leur choix.
- Support : diapo 4

## 45-60 min — Les risques
- Objectif visé : O7
- Le prof : présente l'erreur qui se propage, l'injection de prompt et les droits excessifs.
- Les élèves : donnent une conséquence possible pour chaque risque.
- Support : diapo 5

## 60-75 min — Activité : repérer une injection de prompt
- Objectif visé : O7
- Le prof : montre un e-mail qui contient une instruction cachée. [À VÉRIFIER] L'e-mail ne vient pas du cours.
- Les élèves : repèrent l'instruction et expliquent ce que l'agent risquerait de faire.
- Support : diapo 6

## 75-85 min — Les protections
- Objectif visé : O8
- Le prof : présente les cinq protections du cours.
- Les élèves : les associent aux risques vus.
- Support : diapo 7

## 85-105 min — Activité : sécuriser un agent
- Objectif visé : O8
- Le prof : circule et aide les groupes.
- Les élèves : proposent en groupe les droits, les validations et les tests d'un agent qui gère des e-mails.
- Support : diapo 8

## 105-110 min — Bilan
- Objectifs visés : O6, O7, O8
- Le prof : résume les règles à retenir.
- Les élèves : notent la protection qui leur semble la plus importante.
- Support : diapo 9

## 110-120 min — QCM
- Objectifs visés : O6, O7, O8
- Le prof : distribue le QCM et le corrige en fin de séance.
- Les élèves : répondent individuellement.

En cas de retard : traiter deux cas d'usage seulement dans l'activité d'architecture.
