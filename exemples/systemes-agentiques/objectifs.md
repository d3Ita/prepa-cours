# Objectifs : les systèmes agentiques

Niveau : licence 3 informatique
Durée totale : 6 h

- O1 : Distinguer un agent d'un chatbot et d'un script.
- O2 : Décrire la boucle d'un agent et justifier une limite d'arrêt.
- O3 : Expliquer comment un agent appelle un outil.
- O4 : Rédiger la description d'un outil clair.
- O5 : Distinguer la mémoire à court terme et la mémoire à long terme.
- O6 : Justifier le choix d'un agent ou de plusieurs agents.
- O7 : Identifier les risques d'un agent.
- O8 : Proposer des protections adaptées à un risque.

## Découpage

Séance 1 : 2 h — O1, O2
Séance 2 : 2 h — O3, O4, O5
Séance 3 : 2 h — O6, O7, O8
