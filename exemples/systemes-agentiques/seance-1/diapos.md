# Un agent poursuit un objectif
- Il choisit lui-même ses **prochaines actions**
- Il peut enchaîner plusieurs actions sans nouvelle demande
> Objectif : O1

# Trois programmes différents
- **Chatbot** : répond à un message, puis attend le suivant
- **Script** : suit des étapes fixées à l'avance
- **Agent** : décide de ses étapes pendant l'exécution
> Objectif : O1
> Insister sur qui décide des étapes, et à quel moment.

# La boucle d'un agent
- **Observer** la situation
- **Décider** de la prochaine action
- **Agir**
- **Observer** le résultat, puis recommencer
> Objectif : O2
> Image à ajouter : schéma de la boucle.

# À vous : déroulez une boucle
- Décidez de la prochaine action
- Le prof vous donne le résultat
- Notez chaque étape
> Objectif : O2

# Quand la boucle s'arrête-t-elle ?
- Quand l'objectif est atteint
- Quand une **limite** est dépassée
  - Nombre maximal d'étapes
  - Budget
> Objectif : O2
> Sans limite, un agent bloqué peut tourner sans fin et consommer des ressources.
