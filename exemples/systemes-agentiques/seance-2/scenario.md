# Séance 2 : les outils et la mémoire
Licence 3 informatique, 2 h. Matériel : vidéoprojecteur, feuilles, QCM imprimés.

## 0-10 min — Rappel
- Objectif visé : O3
- Le prof : fait rappeler les étapes de la boucle d'un agent.
- Les élèves : les redonnent à l'oral et demandent comment un agent peut agir.
- Support : diapo 1

## 10-25 min — À quoi sert un outil ?
- Objectif visé : O3
- Le prof : présente le rôle des outils et le déroulement d'un appel.
- Les élèves : posent leurs questions.
- Support : diapos 2 et 3

## 25-40 min — Activité : jouer un appel d'outil
- Objectif visé : O3
- Le prof : distribue les rôles de modèle, de programme et d'outil.
- Les élèves : jouent un appel d'outil par groupe de trois.
- Support : diapo 4

## 40-50 min — Qu'est-ce qu'un bon outil ?
- Objectif visé : O4
- Le prof : présente les qualités attendues et l'importance de la description.
- Les élèves : repèrent ce qui manque dans une description trop vague.
- Support : diapo 5

## 50-75 min — Activité : décrire un outil
- Objectif visé : O4
- Le prof : circule et aide les groupes.
- Les élèves : rédigent par deux le nom, la description, les paramètres et les erreurs d'un outil.
- Support : diapo 6

## 75-90 min — Deux types de mémoire
- Objectif visé : O5
- Le prof : présente la mémoire à court terme et la mémoire à long terme.
- Les élèves : classent des informations dans l'une ou l'autre.
- Support : diapo 7

## 90-105 min — Activité : que faut-il conserver ?
- Objectif visé : O5
- Le prof : anime la mise en commun.
- Les élèves : choisissent ce qu'un agent doit conserver et justifient leur choix.
- Support : diapo 8

## 105-110 min — Bilan
- Objectifs visés : O3, O4, O5
- Le prof : résume les points clés.
- Les élèves : notent ce qu'ils retiennent.
- Support : diapo 9

## 110-120 min — QCM
- Objectifs visés : O3, O4, O5
- Le prof : distribue le QCM et le corrige en fin de séance.
- Les élèves : répondent individuellement.

En cas de retard : faire jouer l'appel d'outil par un seul groupe devant la classe.
