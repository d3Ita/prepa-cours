# Objectifs : les systèmes agentiques

Niveau : licence 3 informatique
Classe : L3 Informatique
Matière : Informatique
Durée totale : 6 h

- OBJ1 : Distinguer un agent d'un chatbot et d'un script.
- OBJ2 : Décrire la boucle d'un agent et justifier une limite d'arrêt.
- OBJ3 : Expliquer comment un agent appelle un outil.
- OBJ4 : Rédiger la description d'un outil clair.
- OBJ5 : Distinguer la mémoire à court terme et la mémoire à long terme.
- OBJ6 : Justifier le choix d'un agent ou de plusieurs agents.
- OBJ7 : Identifier les risques d'un agent.
- OBJ8 : Proposer des protections adaptées à un risque.

## Découpage

Séance 1 : 2 h — OBJ1, OBJ2
Séance 2 : 2 h — OBJ3, OBJ4, OBJ5
Séance 3 : 2 h — OBJ6, OBJ7, OBJ8
